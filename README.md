# paradise-nursury
A Shopping Cart Application called Paradise Nursury using React and Redux
=======
# React + Vite
  This application uses react + vite .

  To install : npm install
  To run: npm run preview
  
==========
# About

*    A dynamic shopping cart application that allows users to browse plants, add them to their cart, and view their order summary. This will include interactive features such as navigation bar, dynamically updating, deleting ,adding and viewing total/Updated costs. 
    


## 🛠️ Tech Stack
* **Frontend:** React.js
* **State Management:** Redux Toolkit (Slices/Store)
* **Styling:** CSS3 (including background image implementations)
* **Tooling:** Vite / Create React App

## 📂 Project Structure
* `src/components/`: UI Components (ProductList, CartItem, AboutUs)
**                  Redux logic and `CartSlice.jsx`
* `src/App.jsx`: Main application routing and landing logic
